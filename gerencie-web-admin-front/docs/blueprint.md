# **App Name**: Gerencie+

## Core Features:

- Login Authentication: Authenticates users against the Xano backend using email and password.
- User Data Retrieval: Fetches user details such as name, email, and role from the Xano API upon successful login.
- Token Management: Securely manages authentication tokens received from Xano.
- Logout Functionality: Allows users to securely log out of the application, clearing user-specific data.
- Error Handling: Gracefully handles login errors, providing informative error messages to the user.

## Style Guidelines:

- Primary color: Deep Blue (#1A237E) for a professional and secure feel, complementing the seriousness of authentication.
- Background color: Light Blue Gray (#ECEFF1) for a clean and unobtrusive backdrop.
- Accent color: Vibrant Yellow (#FFEB3B) to highlight interactive elements like buttons and alerts.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text, providing a modern and readable interface.
- Use simple, clear icons from a set like Material Design Icons to represent user roles and actions.
- Implement a centered layout with a clear, card-based design for login and user info display to focus user attention.
- Incorporate subtle animations, such as a loading spinner, during the authentication process to provide user feedback.
